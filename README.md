# OI Tree Visualizer @ Luogu

在洛谷页面右侧嵌入树形结构可视化工具，支持 DFS/BFS/LCA/直径/重心/重链剖分 动画演示。

## 🚀 一键安装
[点击这里安装脚本](https://raw.githubusercontent.com/DisillusionINF/oi-tree-visualizer/main/oi-tree-visualizer.user.js)
*(点击后会自动弹出 Tampermonkey 安装界面)*

## ✨ 功能介绍
- 强大的树形结构绘制与拖拽
- 算法动画演示：DFS / BFS / LCA逐步 / LCA倍增 / 树的直径 / 树的重心 / 重链剖分
- 支持 JSON 导入/导出，支持导出 PNG 图片
- 快捷键与右键菜单无缝编辑节点
